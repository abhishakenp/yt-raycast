# Institutional / public sector

Set `siteType` to `institutional`.

## Pages
- Home, Notices, Careers, Contact (add About, Services if prompt fits).

## Homepage sections
- `navbar` with clear links to notices and careers.
- `notice-board`, `document-list`, `careers-table` where appropriate; formal tone; strong contrast.
- Avoid ecommerce sections unless the prompt asks for a store.

## Content
- Dated list items for notices; downloadable document metadata in `items`.
- `pageRole`: `citizen-service`, `transparency`, `careers` on respective routes.
