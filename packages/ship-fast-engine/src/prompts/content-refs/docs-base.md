# Documentation site

## Pages

- Home, Docs (sidebar + content), API reference or Guides, Changelog optional, Contact/Support.

## Layout

- First page section often `navbar` then `docs-content` with `items` for nav tree (titles + anchors/hrefs).
- `layoutType` may be `app-shell` for multi-column docs.

## Content

- Use `contentBlocks` for endpoint descriptions, code-adjacent prose, and warnings.
- `pageRole` for docs: `overview`, `reference`, `tutorial`.
