# Design system reference: documentation (base)

## Role

Findability and reading comfort: search, navigation tree or topic grid, code samples when developer-facing.

## Minimum sections (thin prompts)

Header with product/docs title + search → quick links or version badge → topic grid (≥6) → featured guides → optional API overview strip → footer with section links.

## Anti-patterns

Heavy marketing gradient over code; missing code font for snippets; cramped line length for prose.

## Tokens

Muted surfaces, clear borders, monospace for code blocks; comfortable line-height for body text.
