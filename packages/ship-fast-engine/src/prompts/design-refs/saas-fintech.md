# Design system reference: SaaS fintech

## Role

Trust-forward: security posture tone, integration hints, role-based language (treasury, ops, finance). No invented licenses or regulatory IDs.

## Minimum sections (thin prompts)

Nav → hero with outcome metric → compliance/security row (generic labels) → integrations strip → features with risk reduction → proof → CTA → footer disclosures placeholder (no fake numbers).

## Anti-patterns

Meme metrics; cartoon bank logos; specific regulator registration numbers unless user provided.

## Tokens

Severe, calm accents; dense but legible tables for pricing when needed.
