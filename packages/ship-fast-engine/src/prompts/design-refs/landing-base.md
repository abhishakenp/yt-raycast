# Design system reference: landing (marketing — base)

## Role

Broad product or service marketing: clarity, one primary conversion path, social proof without clutter. Dark-first; one accent anchored to mood (not default violet-gray).

## Minimum sections (thin prompts)

Nav → hero (pill + headline + sub + single CTA) → logo row or stats → features 2×2 → bento or highlight band → testimonial or quote → pricing or plan teaser if subscription implied → final CTA → footer with columns.

## Anti-patterns

Sparse single-column-only page; interchangeable icon trio hero; fake brand logos as empty pills; invented certifications or registration numbers.

## Tokens

Deep background (#0a0e1f–#0f172a), surface step-up, hairline borders rgba(255,255,255,0.06–0.10), body #cbd5e1, headings #fff. Display font for hero; readable sans for UI.

## Interaction

One inline script block for mobile nav + optional carousel/tabs per project needs; guard null DOM nodes.
