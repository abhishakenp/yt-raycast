# Design system reference: blog / editorial (base)

## Role

Reading rhythm: featured story + list/grid of posts with categories and metadata.

## Minimum sections (thin prompts)

Nav → featured article band → post grid (≥6) with category labels → optional newsletter → archive or tags → footer.

## Anti-patterns

Card grid without excerpts or dates; single post only for “blog” site type without list.

## Tokens

Readable measure; subtle borders; clear hierarchy between featured and list.
