# Design system reference: community (base)

## Role

Participation: topics, members, activity, clear rules and join path.

## Minimum sections (thin prompts)

Hero with community promise → stats or member count line (plausible) → topic or thread cards → join CTA → guidelines strip → footer.

## Anti-patterns

Empty forum UI with no sample threads; fake member counts as huge round numbers without context.

## Tokens

Warm but structured; clear thread/post hierarchy.
