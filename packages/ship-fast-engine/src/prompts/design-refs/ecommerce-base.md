# Design system reference: e-commerce (base)

## Role

Merchandising and conversion: discover → trust → add to cart. Editorial light canvas or disciplined dark; product and category first.

## Minimum sections (thin prompts)

Promo strip optional → header with search + cart affordance → category tiles (≥4) → featured grid (≥6 SKUs with price) → bundle or story band → reviews → newsletter → multi-column footer.

## Anti-patterns

SaaS pricing-as-hero without products; icon-only grid without prices; missing cart in header for store flows.

## Tokens

Near-black type on light OR high-contrast dark retail; one accent; clear price hierarchy.

## Commerce UI

Real button elements for cart actions; visible bag/cart control in header when appropriate.
