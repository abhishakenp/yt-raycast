# Design system reference: e-commerce fashion / luxury

## Role

Editorial retail: lookbooks, material story, size/fit hints, premium grid density, restrained palette (wine/black/cream family common).

## Minimum sections (thin prompts)

Promo strip → nav with search + cart → hero with collection story → category tiles (≥4) → featured grid with compare-at when sale → editorial band → reviews with style cues → newsletter → footer.

## Anti-patterns

Tech SaaS feature trio as hero; violet template; fake designer trademarks.

## Proof

Stars and “verified buyer” style without inventing legal entity names.
