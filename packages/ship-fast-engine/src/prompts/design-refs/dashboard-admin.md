# Design system reference: admin / analytics dashboard

## Role

Dense tables, filters, saved views, export hints. Meaningful column headers; empty states with “import” or “connect” tone.

## Minimum sections (thin prompts)

Sidebar + topbar → KPI row → chart placeholder with axis labels → primary table with sort affordances → detail drawer optional.

## Anti-patterns

Placeholder “Lorem” in KPI numbers; charts without axis text.

## Tokens

Grid-aligned numerals; zebra or row hover; compact padding.
