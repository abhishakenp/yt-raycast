# Design system reference: dashboard / app (base)

## Role

Operational density: sidebar + main; tables, filters, empty states that teach next step.

## Minimum sections (thin prompts)

Shell: sidebar nav + top bar → main with title + primary action → filter row or tabs → primary table or widget grid → secondary panel optional.

## Anti-patterns

Marketing hero inside authenticated dashboard unless prompt says marketing shell; fake analytics numbers without labels.

## Tokens

Compact padding; clear separation shell vs canvas; status colors for alerts/success.
