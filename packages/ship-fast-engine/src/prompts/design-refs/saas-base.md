# Design system reference: SaaS (base)

## Role

Software product narrative: problem → solution → proof → plans. Dense enough to feel product-led; avoid brochure emptiness.

## Minimum sections (thin prompts)

Nav → hero with product promise → integrators or logo row → 4–6 feature blocks with outcomes → mid-page CTA → social proof → pricing table or tier cards if B2B → FAQ or security row → footer.

## Anti-patterns

Retail storefront hero on non-commerce prompts; dashboard chrome unless prompt asks for app UI; vague “AI-powered” with no concrete capability lines.

## Tokens

Dark surfaces; single strong accent; monospace for code or API hints when relevant.

## Motion

Subtle hover on cards and CTAs; `@media (prefers-reduced-motion: reduce)` respected.
