Getting Started

After installing ChatVault, the first thing you’ll want to do is set up a secure vault and add a source.

  1. Download the latest release from the GitHub repository.
  2. Run chatvault init to create a local vault directory.
  3. Open the app, go to Settings → Security and set a strong passphrase.
  4. Navigate to Import and connect your first provider (OpenAI, Claude, Gemini, …).

Importing Chats

ChatVault supports one‑click imports from the major AI providers.

OpenAI

Enter your API key, select the date range, and click Import. Chats are stored locally with AES‑256 encryption.

Claude

Provide your Anthropic token. The importer automatically deduplicates messages across runs.

Gemini

Link your Google account, pick the projects you want, and let ChatVault fetch the conversations.

Encryption & Security

All data is encrypted at rest using AES‑256‑GCM. The encryption key is derived from your passphrase with PBKDF2 (200 000 iterations).

  • No plaintext data is ever written to disk.
  • Only the local user can decrypt the vault; the server never sees your passphrase.
  • Optional hardware‑backed key storage (e.g., macOS Keychain, Windows Credential Manager).

FAQ

Can I sync my vault across devices?
Yes – export the vault as an encrypted JSON file and import it on another machine.
What happens if I lose my passphrase?
Unfortunately, without the passphrase the data is unrecoverable. Keep a secure backup.
Is there a limit to the number of chats I can store?
Only the storage capacity of your device limits you. The app is optimized for large collections.
