Frequently Asked Questions

What is Chat Collector?

Chat Collector is a desktop‑first application that lets you import, store, and search your AI chat histories from providers like OpenAI, Anthropic, and Gemini—all on your own device, without any cloud sync.

Which AI providers are supported?

Out of the box we support OpenAI (ChatGPT), Anthropic (Claude), and Google Gemini. Additional providers can be added via plugins or future updates.

Is my data stored locally?

Yes. All chat logs are saved in an encrypted SQLite database on your computer. No data is sent to external servers unless you explicitly export it.

How do I import chats?

Click the “Import Now” button on the homepage or go to Settings → Import. You can import from JSON exports, browser extensions, or directly via the provider APIs after authorizing access.

Can I tag or organize chats?

Absolutely. While importing you can assign tags, and later you can edit tags, create folders, or use the built‑in search to filter by keywords, date, or provider.

Is there a free version?

The core functionality is free and open‑source. Premium features such as cloud backup, advanced analytics, and priority support are available via a subscription on the Pricing page.

How do I report a bug?

Visit our Contact page and fill out the bug report form, or open an issue on our GitHub repository.

Will there be regular updates?

Yes. We release updates monthly, adding new providers, UI improvements, and security patches. You can enable automatic updates in the Settings panel.
