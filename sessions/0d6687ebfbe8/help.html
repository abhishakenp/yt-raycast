Getting Started

Chat Collector is designed to be intuitive. Follow these steps to begin archiving your AI conversations:

  1. Click the Import Chats button in the navigation bar.
  2. Select the provider(s) you want to import from (OpenAI, Anthropic, Gemini).
  3. Choose a date range or import all available history.
  4. Review the preview and confirm the import.
  5. All chats will appear in your local archive, ready for tagging and searching.

Frequently Asked Questions

How does Chat Collector keep my data private?

All data is stored locally on your device. No data is sent to external servers unless you explicitly export it. The app runs offline by default, ensuring full privacy.

Can I import chats from multiple providers at once?

Yes! The import wizard supports selecting multiple providers in a single session. The tool automatically deduplicates overlapping conversations.

What file format is used for the archive?

Chats are saved as JSON files inside a structured folder hierarchy. This format is both human‑readable and easy to import into other tools.

How can I delete a conversation from a provider after archiving?

Use the Check‑out feature in the dashboard. Select the conversation(s) you wish to remove, then click “Delete from Provider”. The local copy remains untouched.
