# Design system reference: marketplace (base)

## Role

Two-sided discovery: trust, categories, listings with clear metadata and CTA to list or buy.

## Minimum sections (thin prompts)

Search-forward header → category tiles → featured listings grid → how it works (3 steps) → trust/reviews → seller or buyer CTA → footer.

## Anti-patterns

Pure SaaS pricing as hero; listings without price or role clarity when buying/selling matters.

## Tokens

Neutral surfaces; accent for CTAs and verified badges (without inventing verification bodies).
