# Design system reference: SaaS developer tools

## Role

Docs-adjacent marketing: code smell, CLI/API/SKUs, copy-pasteable patterns, monospace accents.

## Minimum sections (thin prompts)

Nav → hero with technical headline → code or command sample block → feature grid with concrete outcomes → logo row → pricing aligned to seats/usage → docs CTA → footer.

## Anti-patterns

Pure lifestyle photography without technical anchor; vague “platform” with no integration point.

## Tokens

Dark UI; syntax-friendly contrast; optional terminal-green accent only if it fits brand.
