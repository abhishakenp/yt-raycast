# Design system reference: game landing (base)

## Role

Key art energy, feature columns, platforms, press or awards line without fabrication.

## Minimum sections (thin prompts)

Hero with title + tagline + primary CTA → feature columns → gallery or screenshot strip → quotes/testimonials → download/store row → footer links.

## Anti-patterns

Confusing SaaS pricing with game prompts unless explicitly commerce; stolen IP names.

## Motion

Respect reduced motion; optional CSS-only hero polish.
