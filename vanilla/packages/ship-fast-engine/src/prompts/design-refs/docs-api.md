# Design system reference: API documentation home

## Role

Endpoint discoverability: base URL pattern, auth overview, quickstart with real-shaped JSON fences, SDK links without inventing package names unless prompt gives them.

## Minimum sections (thin prompts)

Search → version selector hint → quickstart 3 steps → languages/SDKs row → endpoint group cards → errors/rate limit row → footer.

## Anti-patterns

Marketing fluff without request/response shape; broken code fence formatting.

## Tokens

Wide layout for tables; monospace for payloads; clear H3 for resource groups.
