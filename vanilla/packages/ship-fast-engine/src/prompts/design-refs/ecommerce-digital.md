# Design system reference: e-commerce digital goods

## Role

License clarity, delivery mechanism, updates/support, refund policy tone without fabricated legal.

## Minimum sections (thin prompts)

Header + cart → hero with product name → feature bullets → pricing card with what’s included → FAQ accordion → trust row (payment icons generic) → footer.

## Anti-patterns

Physical shipping copy for pure digital; fake license keys UI with real-looking secrets.

## Tokens

Dark or light with crisp contrast; monospace for license or download hints.
