# Design system reference: portfolio (base)

## Role

Work first: grid or case-study cards, strong typography, about and contact that feel human.

## Minimum sections (thin prompts)

Intro hero with name/discipline → work grid (≥6 projects) → optional client row → about → contact with form affordance.

## Anti-patterns

Empty placeholder sections; generic “services” trio without work samples; SaaS pricing blocks for creative portfolio.

## Tokens

Editorial display type; generous whitespace; imagery or gradient placeholders with intent.
