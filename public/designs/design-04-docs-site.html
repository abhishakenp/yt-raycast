Overview

Build pages that feel designed, not generated.

Aurora Docs is the reference for teams shipping liquid-style UIs and Aurora pipeline presets. It covers how to structure guides, embed code with minimal chrome, and keep one accent across long pages. Use this layout as the baseline for internal docs, API references, and handoff notes to product design.

Principle
One accent per view
A single accent color does more work than a rainbow of competing highlights.
Principle
Vertical rhythm
Separate ideas with contrast and spacing—not identical boxes.
Tip
Use short prompts. Enforce polish in the pipeline.
Aurora preset
The generator can add hero signatures, surface tokens, and section ordering without the user writing a long spec.
