# Template Token Map — v1 (Dark Theme)

All tokens are UPPER_SNAKE_CASE strings embedded directly in the HTML.
The customization layer does a simple string replace for each token.

## Global Tokens (all templates)

| Token | Section | Description |
|---|---|---|
| `BRAND_NAME` | Nav, Footer | Company/product name |

## Nav Tokens

| Token | Description |
|---|---|
| `NAV_LINK_3_TEXT` | Third nav link label |
| `NAV_LINK_3_HREF` | Third nav link URL |
| `NAV_CTA_TEXT` | Nav CTA button text |
