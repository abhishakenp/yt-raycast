Medusa is bundled under medusa-backend/ (Medusa v2, aligned with @medusajs/js-sdk ^2.13.x).

Full stack in Docker (Postgres + Redis + Medusa on :9000):

  bun run medusa:docker

First database migration + demo seed (host tooling against localhost:5432):

  cp medusa-backend/.env.example medusa-backend/.env
  bun install --cwd medusa-backend
  bun run medusa:bootstrap-db

  (Postgres must be reachable at DATABASE_URL; bootstrap-db runs medusa:up + wait + migrate + seed.)

Stop:

  bun run medusa:docker:down

Databases only (run Medusa locally with bun run medusa:dev):

  bun run medusa:bootstrap-db
  bun run medusa:dev

Store API: http://localhost:9000 — Admin: http://localhost:9000/app

Set STORE_CORS / AUTH_CORS for your Next origin. Publishable key → NEXT_PUBLIC_MEDUSA_PUBLISHABLE_KEY on the exported Next app.
